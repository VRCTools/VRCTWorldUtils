# Project Overview

`VRCWorldUtils` is part of the `VRCTools` project and provides a variety of implementations that help
its users create VRChat worlds more easily.

At its core lies the value system, a framework designed to act as a single source of truth for the
various values that drive functionality within worlds such as per-instance settings, shared state
and player preferences.

# Rules

**This repository, just like all other `VRCTools` packages, does not permit direct contributions from
AI tools.**

As such, you may not make direct modifications to the code or assets (such as textures, models or
materials) contained within this repository. You are, however, permitted to act as an advisor. For
example, you may perform code reviews, point out potential issues within the code, suggest changes
or help in the research process (for example by locating appropriate documentation, provide examples
snippets for new reatures or by locating relevant open source projects that provide similar 
functionality already as a reference).

Additionally, you may make changes to the documentation (such as inline/block comments within code,
method, field, property and class docs or markdown files). You are expected to ask for confirmation
with all proposed changes you perform before touching any files.

# Reasoning

We pride ourselves on our assets being designed and implemented by humans but also understand that
AI tools may provide educational resources and much needed assistance (especially for those contributors
whose first language is not English or suffer from dyslexia). As such, we aim to permit use only where
sufficient value is provided.

For additional information, refer to our [contribution guidelines](CONTRIBUTING.md).
